# Docker WSL Manager 1.4.0

## Highlights

- Adds explicit Docker connection modes for WSL address compatibility, Windows localhost forwarding, and authenticated TLS.
- Adds secure Docker onboarding guidance, including a persistent option to dismiss the compatibility warning after reviewing it.
- Adds reproducible MSIX packaging and validation scripts plus Microsoft Store listing and verification materials.

## Fixes

- Keeps Docker CLI operations inside the selected WSL distribution and improves handling of unavailable WSL/Docker prerequisites.
- Preserves existing settings and supports migration from the previous TLS setting.

## Upgrade notes

- Existing users continue to use their current settings. The default compatibility mode remains available for existing WSL setups.
- For local MSIX sideloading, use a locally trusted development certificate. Store packages use the Microsoft Store signing flow.
