# Docker WSL Manager 1.3.0

## Highlights

- The Containers tree now restores the selected container and each group's expanded or collapsed state after an application restart. Saved state is reconciled safely when containers or groups have changed. ([#47](https://github.com/dvdmchl/docker-wsl-manager/issues/47))

## Fixes

- Docker refresh and reconnect work now runs without blocking the JavaFX interface, keeping the application responsive after Windows resumes or Docker becomes temporarily unavailable. ([#46](https://github.com/dvdmchl/docker-wsl-manager/issues/46))
- Closing the application now stops active refresh, log, and statistics work cleanly.

## Upgrade notes

- No migration or configuration changes are required.
